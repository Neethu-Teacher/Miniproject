# ABC Company Employee Data Analysis

## Project Overview
This project analyzes employee data from ABC Company using Python.

## Dataset
The dataset contains 458 rows and 9 columns.

## Data Preprocessing
- Replaced height values with random numbers between 150 and 180.

## Analysis Tasks
1. Employee distribution by team and percentage.
2. Employee distribution by position.
3. Predominant age group.
4. Salary expenditure by team and position.
5. Correlation between age and salary.

## Visualizations
Created charts for all five analysis tasks.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run
1. Open the Python notebook in Google Colab.
2. Upload the CSV dataset if required.
3. Run the code cells in order.

## Conclusion
This project explores employee distribution, age groups,
salary expenditure, and the relationship between age and salary.
